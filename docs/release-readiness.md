## 真实宿主 UI 验收（2026-09-19）

经用户授权，使用独立 Playwright 浏览器连接本机 dsh Web 0.1.5-rc.2。常规登录认证，无模型消息发送。已核对安装的前端、宿主及 Python 工具与发布候选一致；本轮修复后重新构建并刷新页面验收。

| 流程 | 结果 |
|---|---|
| 设置 → Obsidian 项目 → 添加临时 Demo → 保存 | 显示保存成功，侧栏出现临时项目并读取 2 篇笔记 |
| 修改临时连接名称和笔记目录 → 保存 | 已打开的侧栏自动显示新名称及另一目录的 QA Alternate Demo 内容，无需重开 |

| 恢复选择 Demo | 手动刷新后正常显示原 Demo |
| 最终本机配置与测试前比较 | JSON 内容完全一致，仅保留原 Stock、Demo 连接 |
| 画面检查 | 侧栏正常渲染，无框架错误覆盖层；截图只截 Demo 侧栏，保存在临时目录 |

验收发现并修复 HTML pattern 问题：浏览器采用 Unicode v 正则规则，项目 ID 字符类中的连字符必须转义。修复后真实浏览器确认带连字符的合法 ID 可保存、包含斜杠的 ID 被拒绝；Node 回归检查也覆盖这两个条件及大写 ID 拒绝。

控制台记录：修复前出现 3 条 pattern 语法错误，刷新加载修复后不再出现。宿主已有一条 git-graph 插件兼容警告，与本插件无关。删除连接后立即切换项目时触发一次 429：旧读取尚未结束，宿主全局单读取限制拒绝重叠请求；点击手动刷新恢复。此限制保留，不将本轮描述为零控制台错误。

本轮只进行单浏览器桌面核心交互验收，未扩展到移动端或多用户场景。只写连接配置，未编辑用户项目笔记或发送 Agent 消息。

GitHub CI 文件已准备但尚未在 GitHub 运行；Linux/Node 22.12 的运行结果待首次 CI。当前实际宿主验收范围仅限 macOS + dsh Web 0.1.5-rc.2，不承诺其他宿主版本兼容。
